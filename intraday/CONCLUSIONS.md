# Intraday 研究结论（结题记录，2026-09-13）

> 一句话：**QQQ 日内（分钟尺度）订单流方向信号的研究走完了完整闭环——从「看似有 +24bps 的 edge」到「信号是 label 伪影、执行不可行、深度特征也无预测力」，以三层独立负面证据收官。**
>
> 本文件是结题总结：全部结论、证据链、方法学遗产与未关闭边界在此一页可读。过程细节见 `STRATEGY.md`（策略原理与订正）、`README.md`（研究状态与代码索引）、根 `CHANGELOG.md`（逐条变更与订正留痕）。

## 1. 研究问题

在 QQQ 上，用 Databento XNAS.ITCH mbo 全量订单簿数据（委托流口径）构建分钟级特征，能否预测未来 6 分钟真实价格方向并扣成本兑现？

## 2. 最终结论（三层，全部为负面）

### 第一层：信号不存在（根因，2026-09-13）

**原「方向判断力」（AUC 0.603 / 0.589）是委托价 label 伪影。**

- 全管道的分钟 close（含 label 锚点 `close_t`）是「该分钟最后一张**新增委托**的价格」——一张委托价，不是市场价。24% 的信号分钟偏离同分钟末笔成交价超过 10bps，16% 超过 20bps，5% 超过 120bps。
- 伪影方向性：做多信号锚点平均低于市场 **−28.8bps**、做空 **+31.0bps**。label「未来 close > 当前 close」学到的主体是「委托价偏离盘口的机械回归」，不是价格预测；模型分档两端（最有把握的）恰恰选出偏离最大的样本。
- **终极检验**（`verify_flabel.py`，label 与评估价全换 F 成交价）：AUC **0.5078（2025）/ 0.5146（2026）≈ 随机**，净 −5.9 / −5.7bps，126 个 walk-forward 窗口 **0 个正**。

### 第二层：执行不可行（表象层，2026-09-13，先于根因发现）

即便在伪影被揭穿之前，三条执行路径已全部测负：

| 执行口径 | fill | 每信号期望 | 出处 |
|---|---|---|---|
| 主动市价（t+1 开盘） | 100%（付滑点） | **−4.8 bps**（每月皆负） | `economics.py` |
| 被动限价·触及口径（乐观上界） | 92.5% / 96.9% | +23.4 / +43.9 bps（伪影世界内部自洽） | `limit_sim.py` |
| 被动限价·队列口径（真实） | **46.0% / 41.1%** | **−1.7 / −2.5 bps** | `queue_sim.py` |
| 主动市价·延迟扫描 0~60 秒 | — | 全程平坦 **−5.3** | `latency_curve.py` |

队列口径的机制是 maker 单逆向选择：marketable（挂单即吃，31.6%）条件收益 −3.9bps，排队成交（fill 时机中位挂单后 1.7 秒——价格瞬间砸穿队列）条件收益 −3.5bps，赚钱的信号队列轮不到。延迟曲线全程平坦的异常正是暴露伪影根因的线索。

### 第三层：深度特征也无预测力（2026-09-13，回应「还没深挖」的质疑）

`deep_features.py` 构建文献背书的 17 个深度特征（CKS 盘口 OFI、前 5 档深度不平衡、撤单流不平衡、成交流不平衡、事件微结构、mid 动量），同 F-label 框架检验（`verify_deep.py`）：

- deep-only AUC **0.5005（2025）/ 0.4854（2026）**，净 −5.8 / −5.6bps，46 个窗口 **0 个正**；
- deep + 原 15 特征拼接 AUC 0.5272，扣成本同样全负。

学术 OFI 的真实预测力集中于**秒级 / 亚秒级**（HFT 领域），分钟聚合稀释到零。

### 三层独立负面证据（交叉验证）

1. 富途成交价口径 5.5 年重训：−6bps（独立数据源，`futu_wf.py`）；
2. 公开技术指标系统性证伪（2026-08-03，quant skill 阶段：趋势 / 回归 × 多标的 × 参数网格，无任何 train+test 双正组合）；
3. mbo 委托流（基础 + 深度特征）在成交价 label 下全部 ≈ 随机。

## 4. 方法学遗产（本项目最有价值的产出）

1. **委托价 label 伪影检验**：任何用 mbo / 盘口数据做 ML 的人，label 锚点必须先对照真实成交价（或 mid-quote）测偏离分布——本项目的「AUC 0.603」曾跨年复现、多重验证仍屹立，最后倒在锚点口径上。这是对所有盘口数据研究的通用前置关卡。
2. **订单簿队列模拟器**（`queue_sim.py`）：事件语义实测（A 挂入 / C 移除 / F 成交配对，经全天重放平衡验证）+ 队列前移 / 成交吃单判定 + marketable 处理 + 同信号对照。触及口径 fill rate 在它面前 92.5% → 46%。
3. **「结果异常即深挖」**：延迟曲线的平坦异常（0~60 秒差 0.1bps）是揭穿一切的线索——数据不会骗人，但口径会。
4. **纪律框架**：坏点清洗（856 个 close=0 坏分钟曾虚增 43bps）、不重叠采样、walk-forward、同口径对照、订正留痕——每一环都被验证过价值。

## 5. 边界：本结论没有关闭什么

- **秒级 / 亚秒级尺度**：学术 OFI 预测力的主场，属 HFT 领域（需 Databento Plus $1,750/月 + 专业低延迟执行基础设施），超出本项目「分钟尺度 + 非专业延迟」的约束，未测。
- **跨标的**：全程仅 QQQ；不同微观结构的标的（浅队列、宽 spread）未测。
- **信号家族**：关闭的是「订单流特征（基础 + 深度）」与「公开技术指标」；跨标的相对价值、事件驱动等家族未测（先验不高，重启需新假设）。
