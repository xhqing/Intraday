## 当前研究状态（2026-09-13 终局 + 新方向启动：A 股隔夜映射初筛出正信号）

- **新方向（2026-09-13 并行启动）**：订单流收官后按 edge 来源机制启动两线——① **A 股跨境 ETF 隔夜映射（`overnight_map.py`）：初筛出正信号**——开盘对隔夜美股反应不足 + 跳空后半小时反向修正，513050 反向口径扣成本 +12~+18bps（n=667/407）、7 年跨年稳定，待执行口径严谨化（见 CHANGELOG 2026-09-13 条）；② 美股开盘动量（`mom_open.py`）：负（QQQ −2.15bps/日、SPY 不单调），文献效应在当前 ETF 上不存在，开盘分支关闭。**A 股隔夜反向线后续（同日）**：执行严谨化（`etf_rev.py`）确认信号真实但利润集中 2020-2022 与开盘第一分钟；近年定版（`etf_recent.py`）2023-2026 净 +1.8bps/日（t=0.34、2026 转负）——信号死亡，该线归档（详见 CHANGELOG）。

- **结论（2026-09-13 晚，根因发现，决定性）：「方向判断力」本身是委托价 label 伪影，信号在真实价格世界不存在（就现有 15 个基础特征而言——深度特征提取未做过，是该结论的未关闭边界，见下）**。发现链：① 延迟扫描曲线（`latency_curve.py`）异常平坦（0~60 秒全 −5.3bps）触发深挖；② 实测信号分钟 close_t（最后一张 A 委托价）与同分钟最后一笔 F 成交价的偏差：**24% 信号 >10bps、16% >20bps、5% >120bps**；③ **伪影方向性**：做多信号 close_t 均值低于市场成交价 **−28.8bps**、做空 **+31.0bps**（中位数≈0，但 qcut 两端专门选出偏离最大的信号）——label「未来 close > 当前 close」的主体是「委托价偏离盘口的机械回归」，不是真实价格方向；④ 真实成交价世界（F 进 F 出）毛期望 +0.2bps ≈ 0；⑤ **终极检验（`verify_flabel.py`）**：特征保持委托流 15 个、label 换 F 成交价方向重训 walk-forward——**AUC 0.5078（2025）/ 0.5146（2026）≈ 随机，净收益 −5.9 / −5.7bps，98+28 窗口 0 个正**：**当前 15 个基础特征对真实价格方向无预测力**；与富途成交价口径 5.5 年 −6bps（独立数据源）交叉验证。→ 深度特征分支（2026-09-13 同日开启并关闭）：`deep_features.py` 构建文献背书的深度特征 17 个（CKS 盘口 OFI / 多档深度不平衡 / 撤单流 / 成交流 / 事件微结构 / mid 动量），`verify_deep.py` 同 F-label 框架检验——**deep-only AUC 0.5005（2025）/ 0.4854（2026），净 −5.8 / −5.6bps，46 个窗口 0 个正；deep+orig 拼接 0.527 同样扣成本全负**。深度家族在分钟尺度无预测力（学术 OFI 预测力集中于秒级，分钟聚合已稀释干净）。至此「分钟尺度 + 非专业延迟」约束下的订单流信号家族（基础 + 深度）全部关闭，订单流方向研究收官；秒级/亚秒级属 HFT 领域（需 Plus 订阅与低延迟执行），超出本项目范围。
- **证据链闭环**：回测上限 +24（A 委托价进 A 委托价出，伪影世界内部自洽）→ 触及 +23.4（同上）→ 队列 −1.7（真实簿上无伪收益）→ 市价 / 延迟曲线 −5.3（真实价格进场无信号）→ F-label 重训 AUC 0.51（根因确认：信号从源头不存在）。执行侧三口径全负只是表象，根因是 label 口径泄漏。当日早些的队列模拟结论（fill 46%、逆向选择）仍成立，但它是第二层死因——第一层是信号本身不存在。
- **订正（留痕）**：以下历史结论中「方向判断力跨年成立（AUC 0.603/0.589）」的表述全部应读作「委托价 label 口径的伪影判断力」；「edge 怕延迟也怕排队」的框架作废（无 edge 可谈）；「信号预测力真实、被否定的是执行形态」作废（预测力本身是伪影）。

- **结论（2026-09-13，队列优先级模拟，决定性负面；→ 同日被根因发现取代，见首条）**：「t+1 限价挂单可交易」被推翻——`queue_sim.py` 用 mbo order_id 级事件重放订单簿队列（事件语义经重放平衡实测验证：A 挂入 / C 移除 / F 成交配对），信号与出场与 limit_sim 完全同口径（同批 5090 信号逐行对齐验证）。**真实队列 fill 只有 46.0%（2025）/ 41.1%（2026），每信号期望 −1.7 / −2.5 bps，两年、分月、分方向、全 δ 网格皆负**。触及口径的 92.5%/96.9% 是严重乐观上界：价格到过挂单价 ≠ 队列轮到你。机制是 maker 单逆向选择：marketable（挂单即吃，占 31.6%）条件收益 −3.9（2025）/−10.5（2026）bps；排队成交（fill 时机中位挂单后 1.7s——价格瞬间砸穿队列）条件收益 −3.5bps——轮到你的成交恰是信号失败方向，而赚钱的信号（价格温和回踩）Q0（挂单时刻队列前置量，中位 200~400 股）一分钟内消化不完轮不到。δ 加深救不了（0~10 美分全负）。「edge 怕延迟不怕被动等」订正为「**edge 怕延迟、也怕排队**」：信号方向判断力（AUC 0.603）真实，但可成交性与盈利性负相关，被动执行形态不存在。Databento Plus 订阅讨论就此关闭（真实 fill rate 落定且期望为负）。
- **结论（2026-08-30，「不可交易」被推翻；→ 2026-09-13 被 queue_sim 再次订正，见上条）**：2026-08-29 曾判定「edge 存活窗口短于一分钟、不可交易（t+1 市价进场 −4.8bps）、Databento Plus 不予考虑」——限价单模拟实验推翻该判定的「不可交易」部分：**edge 怕延迟但不怕被动等**。t+1 分钟内以信号价挂限价单（δ=0，maker 进 0 + taker 出 3bps），2025 年 5090 信号：**fill 92.5%（strict 穿过半 tick 口径）、成交笔均 +25.3bps、每信号期望 +23.4bps**——与回测口径 +24.0bps 同量级，而同位置主动市价 −4.8bps。方向对称（多 +24.0 / 空 +26.6）、四个月全正（+29.0 / +25.8 / +27.5 / +12.3）、δ 越深期望越低（挂当前价不追价最优）。~~保留：fill 是分钟触及口径的乐观上界，真实队列优先级 fill rate 待 order_id 级模拟~~（已做，触及上界被击穿，见首条）
- **结论（订正存档，2026-08-29）**：2025 年跨年验证原报「+64.7 bps/笔」经逐笔明细复核订正——① 坏点（盘后 close=0 伪影 856 分钟）31 笔假交易虚增 43bps；② 剔坏点后 **+24.0 bps/笔（AUC 0.603、88/98 窗口正、3596 笔），2026 年修正版 +39.2 bps（AUC 0.589、18/20 正）**——方向预测力跨年稳健成立；③ t+1 开盘市价进场 −4.8bps（每月皆负）——主动吃延迟拿不到 edge
- **信号衰减曲线（2026-09-13 扩展至 60 分钟，`decay_curve.py`）**：H=1..60 各自独立 walk-forward（H=7..60 为 2026-09-13 新扫，完全同口径）——**稳健 edge 区 H≤12**（正窗口占比 92%→80%、净 +24~+21bps/笔）；**衰减带 H≈13~24**（正窗口 66%→53%，净值 +17~+12bps 仍正但靠少数窗口撑）；**H≈25~30 起 edge 归零**（正窗口 49%、净 +3~+9bps 与噪声同量级）；H=40~60 纯噪声区（正窗口 40%、净 +4bps，AUC 残留 ~0.55 不构成可交易 edge）。每分钟 edge 密度从 H=1 的 25.7bps/分钟降到 H=60 的 0.05bps/分钟（两个数量级）——判断力集中在前几分钟，其后是随机游走。原 H=1..6 结论（AUC 0.638→0.603、净 +25.7~+21.5）不变，6 分钟外没有新 edge，只有衰减
- **口径结论（2026-08-16~17）**：mbo 聚合分钟（委托簿口径）与富途 1m（成交价口径）特征相关 ≈0，两个口径是不同的信息世界；富途成交价口径 5.5 年重训验证无 edge（−6bps/笔，futu_wf.py 819 窗口）
- **实盘数据成本（讨论已关闭，2026-09-13）**：与训练口径一致的实时 mbo 需 Databento Plus $1,750/月 + 流量 ~$29/月（实时 XNAS.ITCH mbo 仅 Plus/Unlimited 含；历史数据按量 $1.20/GB 不需订阅）——队列优先级模拟落定真实 fill 期望为负（见首条结论），订阅不值得，讨论关闭
- **关键定稿**：
  - 不重叠采样（label 窗口 = 持仓窗口 = 6 分钟，样本不重叠）
  - 无止损时 R 口径 = 双向 risk = entry price（收益率是 R 的特例，两口径严格相等）
  - 训练/测试解耦（train.py 固化模型，test.py 载入，改止损不重训）
  - **坏点清洗（2026-08-29 增）**：分钟数据剔除 close≤0（盘后聚合伪影），否则做空假赚 100% 虚增收益
- 数据备份：GitHub Release `tick-2025-08-23`（2025 全量 + 2026 增量 + manifest）、`tick-full-2026-08-08` / `tick-full-2026-08-06`

## 风险与局限（诚实）

- 仅 QQQ 单标的；时间上已跨 2025-2026 两个年份（118 天、4000+ 笔），但跨标的未验证
- **队列模拟近似（2026-09-13）**：忽略自身挂单对簿的影响（净单 << 档位深度）、部分成交即按全成计、marketable 判定只扫对手侧 ±5 tick（更远视为错价单）、挂单时刻假设信号计算零延迟（真实延迟只会让 fill 更低，当前口径已偏乐观）；Nasdaq displayed order 严格 FIFO 语义按事件序重放，C 事件 leave-qty 语义经全天重放平衡验证（深度平稳 / bid<ask / spread 1 tick）
- 净收益对成本假设敏感（限价口径 maker 0 + taker 3bps；市场动荡时点差扩大、撤单重挂的隐性成本未计）——但队列口径下毛期望已为负，成本假设不再影响「不可交易」结论
- 信号密集时段一次一仓会跳过信号；跳过的信号分布是否随机未严格验证
